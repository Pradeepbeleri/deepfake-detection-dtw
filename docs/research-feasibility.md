## AV-HuBERT: verified upstream evidence

[Official AV-HuBERT repository](https://github.com/facebookresearch/av_hubert), inspected at commit `258fb50e155134eec2c4b49c2ae8de267075fd18`, describes self-supervised audio-visual speech representation learning, lip reading and speech recognition; it links the [representation paper](https://arxiv.org/abs/2201.02184), [robust AVSR paper](https://arxiv.org/abs/2201.01763), a [checkpoint catalogue](https://facebookresearch.github.io/av_hubert/), and a Colab demonstration. Its speech checkpoints are not trained deepfake classifiers. The documented installation uses Python 3.8, a Fairseq submodule, editable Fairseq installation and pinned dependencies in [requirements.txt](https://github.com/facebookresearch/av_hubert/blob/258fb50e155134eec2c4b49c2ae8de267075fd18/requirements.txt); the README shows Fairseq checkpoint loading and describes 25 Hz AV-HuBERT feature labels. Compatibility with current Colab, Python 3.12, CUDA and modern packages is untested. Pin the submodule commit as well as the upstream revision; do not assume current Fairseq works.

**License gate:** [official license](https://github.com/facebookresearch/av_hubert/blob/258fb50e155134eec2c4b49c2ae8de267075fd18/LICENSE) grants rights solely for non-commercial research and explicitly restricts production, surveillance and biometric processing. Whether the proposed identity-impersonation use constitutes a restricted use requires institutional review; do not assume research status resolves it. Check separate checkpoint terms and any downstream licenses. A premium research interface does not itself authorize production deployment. Consider a suitably licensed alternative if review does not permit this use.
