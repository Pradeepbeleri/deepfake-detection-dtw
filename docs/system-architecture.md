# System architecture (proposed)

No components below exist yet. Separate research training from deployment inference, with explicit artifact versions and dataset provenance.

1. Ingest permitted video in an isolated worker; probe streams, enforce resource limits, decode timestamps and extract synchronized audio and frames. Detect/track face and mouth; retain quality and missing-data flags. Reject unsupported, silent, multi-face ambiguous or unusable clips with a clear reason rather than a fabricated prediction.
2. Produce audio and visual temporal representations with approved encoders. The current fallback candidate uses separate Whisper audio and independently initialized visual encoders; it has no pretrained joint audio-visual representation. Compare using a validated shared representation; bounded DTW yields timing features with units and quality metadata. The independently trained baseline temporal head and optional feature-fusion head produce logits. Training artifacts include code, configuration, checkpoint hash, data split and license provenance.
3. A versioned inference adapter loads an explicitly configured, approved model and calibration artifact. Without them it reports model unavailable. Scores and classification thresholds are only shown with appropriate validation/calibration; timing evidence is not a separate authenticity verdict.
4. FastAPI offers versioned upload/job/status/result interfaces, with validation, bounded asynchronous processing, timeouts, cancellation and explicit states: queued, processing, complete, unsupported, failed, unavailable. Return schema version, model version, score semantics, quality flags and evidence timestamps. Design authentication/authorization, abuse limits, encryption and retention based on deployment threat model. Use random IDs, private storage, safe temporary paths and isolated media decoding; never trust filenames or MIME alone.
5. React/TypeScript client displays upload, preview, honest progress, outcome, limitations, and deletion. Responsive accessible UI consumes the same API state machine; do not infer progress from a timer. Poll or stream actual job state.

Keep media and facial data private, minimize retention, support deletion, redact logs and avoid sensitive data in URLs. Define deployment-specific consent and retention policies before collecting real user video. Queue/storage technology, authentication and hosting are not selected. Model unavailability and safety limitations are first-class API results; no mock scores in production.
